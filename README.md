🏦 **Account Management System**

A Kotlin-based bank account management system demonstrating core Object-Oriented Programming principles including Encapsulation, Inheritance, and Polymorphism.

📖 **About The Project**

This project implements a simple banking system with different account types, each with unique withdrawal rules and features. It was created as a learning exercise to demonstrate OOP concepts in Kotlin.


🎯 **Features**

Base Account Class: Core banking operations (deposit, withdraw, balance inquiry)

Savings Account: Withdrawal limit of $500 per transaction

VIP Account: Automatic transaction fee ($2.00) applied to withdrawals

Polymorphism: Unified interface for managing different account types
